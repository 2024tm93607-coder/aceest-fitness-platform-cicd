# ACEest Fitness & Gym - Core Platform (v1.0)

## Project Overview
This repository contains the foundational backend services for ACEest Fitness & Gym. As part of our transition to a robust DevOps architecture, this baseline version (v1.0) migrates legacy logic into a modular Flask web application. It establishes the "Single Source of Truth" for gym programs and system health monitoring, integrated with a professional CI/CD pipeline.

---

## Technical Stack
* **Framework**: Flask (Python 3.11)
* **Testing**: Pytest
* **Containerization**: Docker
* **Orchestration**: Jenkins & GitHub Actions
